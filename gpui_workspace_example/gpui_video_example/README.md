# 映刻 · FRAME — GPUI Video Player

使用 `gpui-kit` 渲染界面，Tokio 处理异步任务；独立播放线程负责媒体探测、解码、打开和跳转，界面线程不等待 FFmpeg 或解码器。

## 界面设计

界面参考 `mai_ui_video_player/design-output/result.html`，采用 `#121212` 深色背景、`#58b4ff` 蓝色强调，以及左侧导航 / 视频舞台 / 待播列表布局。

- **正在播放**：山湖落日占位封面、真实视频舞台、进度预览、播放控制、音量、倍速、字幕和全屏。未加载时明确标注设计封面，不伪造媒体信息或播放进度。
- **接下来播放**：显示实际打开的文件和当前播放项；窄窗口下移至视频下方，导航收起为图标；全屏时只保留画面与控制栏。
- **章节清单**：读取文件中的真实内嵌章节，点击跳转；无章节时显示说明，不使用设计稿中的虚构章节。
- **媒体库**：最近观看、断点进度和收藏夹。爱心按钮收藏 / 取消收藏；缺失文件保留记录并禁止播放。列表中的山湖缩略图为统一示意封面，而不是视频截图。
- **播放设置**：速度、原始画质信息、音量、字幕样式、深浅主题及高级操作；偏好和收藏自动保存，兼容原有配置。
- 本地视频以原始画质播放，不提供虚假的 4K / HDR 选项；画中画尚未实现，按钮禁用并说明原因。

界面布局集中在 `src/ui.rs`，播放与解码逻辑沿用原有模块。默认窗口为 1440 × 900，最小为 760 × 560，页面支持纵向滚动。

## 运行

需要安装 `ffmpeg` 和 `ffprobe` 并加入 `PATH`（macOS：`brew install ffmpeg`）。媒体探测、音频保音调变速、内嵌字幕和缩略图均使用 FFmpeg，因此硬件解码路径也需要这些程序。

```sh
cargo run -p gpui_video_example
cargo run -p gpui_video_example -- /path/to/movie.mp4 /path/to/next.mkv
```

## 播放与操作

- **Open videos** 支持一次选择多个文件形成播放列表；**Playlist / Previous / Next** 切换视频，播放结束自动播放列表中的下一项。也可将视频或 SRT 文件拖入窗口。
- 文件选择框支持 MP4、M4V、MOV、MKV、WebM、AVI；不支持的类型在系统允许时置灰。后端同样检查类型并实际探测视频流，不只是放宽扩展名过滤。
- **Fullscreen**、双击画面或 `F` 切换全屏，`Esc` 退出；点击画面获得键盘焦点。空格暂停/继续，左右键跳转 5 秒，`Shift`＋左右键跳转 30 秒，上下键调整音量，`M` 静音。
- 进度条支持点击和拖动跳转；拖动时保留原播放/暂停状态，松开后恢复。悬停可查看缩略图和目标时间；缩略图由独立线程生成，不阻塞播放。
- 到结尾进入 **Ended** 状态，**Replay** 从头播放；**Loop** 循环当前文件，优先于自动播放下一项。
- **Speed** 提供 0.5×、0.75×、1×、1.25×、1.5×、2×、3×。音频使用 `atempo` 保持音调；画面、音频和字幕共享媒体时间。跳转后保留倍速。
- **Frame +** 或 `.` 暂停并前进一帧，`,` 后退；后退优先定位到最近显示的帧，跨越历史缓存时按帧率估算位置。
- **Screenshot** 将当前显示的视频帧保存为 PNG，**不包含 GPUI 字幕和控件叠层**。
- **Audio track** 按语言、编码和标题选择音轨，或选 **No audio**。设备或音频解码失败时显示警告并继续无声播放。

## 字幕

- 自动查找同目录的 `movie.srt`，也支持 `.SRT`、`movie.zh.srt`、`movie.en.srt`；无精确同名文件时优先中文，其次英文，再按文件名排序。
- **Open SRT** 手动加载外挂字幕；**Embedded subtitles** 选择媒体中的文本字幕轨。位图字幕会在菜单中禁用，ASS 等文本轨经转换后仅保留可转换为 SRT 的文本内容。
- 支持 UTF-8（含 BOM）和带 BOM 的 UTF-16 LE/BE；其他编码请先转换为 UTF-8。SRT 按纯文本渲染，不执行样式标签。
- **Subtitle settings** 调整提前/延后、12–64px 字号、描边、背景透明度，以及顶部/中部/底部位置；正延迟表示字幕晚显示。
- **Subtitles** 显隐状态和样式会保存；自动加载字幕不会擅自打开已关闭的字幕，手动选择字幕会启用显示。坏字幕不会中断视频播放。

## 断点与设置

- 保存每个文件的播放位置和外挂字幕路径；**Recent** 显示最近 20 个文件。已播放结束的文件从头打开。
- 音量、静音、倍速、循环和字幕设置重启后保留；播放期间每 10 秒保存进度，切换视频及正常关闭窗口时也会保存。
- macOS 默认位置：`~/Library/Application Support/gpui-video-player/settings.json`；其他系统使用 `$XDG_CONFIG_HOME/gpui-video-player/settings.json` 或 `~/.config/gpui-video-player/settings.json`。
- 可设置 `GPUI_VIDEO_CONFIG=/path/to/settings.json` 指定配置文件。写入采用临时文件加重命名；配置损坏时保留原文件并提示，当前会话使用默认设置且不覆盖坏文件。

## 解码与渲染

- 兼容的 H.264 优先使用 `gpu-video` 硬件解码；其他编码、旋转视频或不支持的硬解色彩空间使用 FFmpeg。硬解运行时失败或 GPU 回读失败也会尝试软件恢复。
- FFmpeg 软件路径保留实际帧 PTS，不强行转为平均帧率，支持可变帧率和媒体旋转信息；直接输出 GPUI 所需的 BGRA，避免逐像素交换通道。
- 硬解颜色转换读取媒体的 BT.709/BT.601 和 Full/Limited 信息。未知 SD 视频使用 BT.601，其他未知视频使用 BT.709。当前不提供 HDR 色调映射或 10-bit 输出。
- 硬解帧仍通过异步 GPU 回读桥接到 GPUI `RenderImage`，**不是零拷贝**。队列有界；暂停时不持续重绘视频。跳转复用探测元数据，但为正确重置参考帧仍重建视频解码器。
- 每个媒体请求带递增编号；尚未执行的旧打开/跳转请求会合并跳过，过期结果不会更新界面。已开始的外部进程不会强行中断，而是在完成或超时后处理最新请求。
- 当前针对本地、具有有限时长的视频文件；不支持直播/网络流、位图字幕渲染或完整 ASS 排版。
