# Ratatui 交互示例

Ratatui 用于终端界面（TUI），本示例展示类似 GUI 的按钮、Tooltip 和模态弹窗，运行在终端中，不创建原生桌面窗口。

```sh
cargo run
```

请使用支持 UTF-8 / 中文、鼠标事件的终端，窗口至少 52 列 × 22 行。鼠标悬停支持取决于终端，键盘始终可用。计数仅保存在内存中。

| 操作 | 鼠标 | 键盘 |
| --- | --- | --- |
| 选择按钮 / 查看提示 | 悬停 | Tab、Shift+Tab、方向键 |
| 执行按钮 | 左键点击 | Enter、空格 |
| 增加计数 | 点击增加计数 | `+` 或 `=` |
| 打开重置确认框 | 点击重置计数 | `r` |
| 关于弹窗 | 点击关于 | `?` |
| 关闭弹窗 | 点击取消 / 知道了 | Esc |
| 退出 | 点击退出 | 主界面 `q` / Esc，任意界面 Ctrl+C |

重置弹窗默认选中“取消”，Tab 或左右键选择“确认重置”。弹窗打开时背景按钮和快捷键不会响应。

代码：`src/main.rs` 管理终端和事件循环；`src/app.rs` 管理状态、按钮命中检测、焦点、提示和弹窗。按钮由 `Paragraph` + `Block` 绘制，浮层用 `Clear` 清除底层内容。

```sh
cargo test
cargo clippy --all-targets -- -D warnings
```
